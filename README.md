## 🚀 Featured Projects

### [GprFlow — Crypto Trading Platform](https://github.com/JosephPshine63)
A fully deployed fullstack platform for real-time crypto trading. Built the entire system from scratch: live price charts via CoinGecko, dynamic portfolio tracking, order history, and a multi-layer auth flow (JWT stateless + OAuth2 Google + OTP 2FA via email/SMS). Integrated Stripe and Razorpay for real payment processing and a Gemini AI chatbot for market analysis.

`Spring Boot` `React` `Redux` `MySQL` `Stripe` `Razorpay` `Gemini AI` `OAuth2` `JWT` `2FA` `Railway` `Vercel`

---

### [Connecting — Real-time Chat App](https://github.com/JosephPshine63)
A WhatsApp Web-inspired messaging app with WebSocket-based real-time communication, global chat rooms, and full identity management via Keycloak (OAuth2 + JWT + roles). The entire infrastructure is dockerized — Postgres, Spring Boot, Angular, and Keycloak all run via Docker Compose, deployable in a single command.

`Spring Boot` `Angular` `WebSocket` `Keycloak` `PostgreSQL` `Docker Compose` `OAuth2 + JWT`

---

### [PioCart — E-Commerce Backend](https://github.com/JosephPshine63)
A complete REST API for an e-commerce platform: product and category management, dynamic cart logic, order processing, and user management. Domain model built with proper JPA relationships (OneToMany, ManyToMany), input validation, and a fully dockerized dev environment.

`Java 17` `Spring Boot 3` `PostgreSQL` `Docker Compose` `ModelMapper` `Lombok`

---

### [BookTribe — Social Reading Platform](https://github.com/JosephPshine63)
A social platform for book tracking and sharing. Built with a fullstack monorepo — Spring Boot backend, Angular frontend, and a self-managed Keycloak realm for identity. Users can manage and share their reading lists with OAuth2-based authentication.

`Spring Boot` `Angular` `Keycloak` `Maven`
